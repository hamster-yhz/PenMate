## 3. 总体结论（基于当前落地）

- 编译状态：`mvn -q -DskipTests test-compile` 已通过。
- 10 个目标服务均已建立对应业务层测试类。
- 覆盖形态：
  - `Style` / `Plugin` / `Agent` / `Rag` / `Ops` / `Model` 已具备较完整主干
  - `Novel` / `Approval` / `IAM` 当前为代表性起步覆盖，仍有明显扩展空间

## 4. 后续增补优先级（建议）

1. `NovelApplicationService`：补齐章节版本、内容提交、大纲、卡片关系链路。
2. `IamQueryApplicationService`：补齐用户/角色增删改、授权增删与菜单查询分支。
3. `ApprovalApplicationService`：补齐 `listByProject`、`reject` 及成功路径。
4. `RagApplicationService`：补齐 `getDocumentUploadUrl`、`listRetrievalLogs` 与嵌入成功分支。

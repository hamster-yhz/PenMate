# PenMate 统一全量后台接口设计 v1.1

> 对齐 [`prd-v0.2`](docs/project-specifications/prd/prd-v0.2.md)、[`DDD架构规范`](docs/project-specifications/backend/DDD架构规范.md)、[`RBAC接口与表结构设计`](docs/project-specifications/backend/RBAC接口与表结构设计.md)。

## 1. 接口总约定

### 1.1 基础约定
- Base Path：`/api/v1`
- 认证：Bearer JWT
- 授权：RBAC权限码 + 项目成员角色
- 幂等：写接口支持 `Idempotency-Key`
- 追踪：响应头 `X-Trace-Id`

### 1.2 响应规范
成功：
```json
{
  "data": {},
  "meta": {
    "traceId": "01HT...",
    "timestamp": "2026-04-12T08:00:00.000Z"
  }
}
```

分页：
```json
{
  "data": [],
  "pagination": {
    "totalItems": 127,
    "totalPages": 13,
    "currentPage": 2,
    "pageSize": 10
  },
  "meta": {
    "traceId": "01HT...",
    "timestamp": "2026-04-12T08:00:00.000Z"
  }
}
```

错误：
```json
{
  "status": 403,
  "errorCode": "INSUFFICIENT_PERMISSIONS",
  "message": "Missing permission novel:project:update",
  "details": null,
  "meta": {
    "traceId": "01HT...",
    "timestamp": "2026-04-12T08:00:00.000Z"
  }
}
```

### 1.3 状态码
- `200` 成功
- `201` 创建成功
- `204` 删除成功
- `400` 参数错误
- `401` 未认证
- `403` 无权限
- `404` 资源不存在
- `409` 冲突
- `422` 业务不可执行
- `500` 服务器异常

## 4. 控件映射结论（聚合）

1. Workbench：已覆盖 novel 主链路（大纲、章节、正文对象存储、版本、卡片、关系、成员、项目标题更新）。
2. DomainConsole：已覆盖 rbac 全量管理动作（用户/角色/权限/菜单/绑定关系）。
3. StyleManager：已覆盖 style 域列表/详情/增改删/切换/样文解析闭环。

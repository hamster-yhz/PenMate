#### 3.1.5 界面及交互

A功能的界面，与界面各元素的说明及其交互（原型图或UI设计稿）

**界面元素说明：**

1. **手机号输入框：**

    - 占位提示文本（Placeholder）：`请输入手机号`
    - 交互：用户输入时，系统可进行实时格式校验，仅允许输入数字。当输入满足11位时，“获取验证码”按钮才变为可点击状态。

2. **“获取验证码”按钮：**
    
    - 默认状态：置灰，不可点击。
    - 激活状态：当用户输入了11位有效手机号后，按钮变为高亮可点击状态。
    - 点击后交互：按钮文本变为“60s后重试”并开始倒计时，期间按钮不可再次点击。倒计时结束后，文本恢复为“获取验证码”。

3. **验证码输入框：**
    
    - 占位提示文本（Placeholder）：`请输入6位验证码`
    - 交互：通常限制输入长度为6位数字。

4. **密码设置输入框：**
    
    - 占位提示文本（Placeholder）：`请设置密码（8-16位字母和数字组合）`
    - 交互：输入内容默认显示为密文（•）。提供一个“眼睛”图标，点击可切换密码的明文/密文显示。

5. **密码确认输入框：**
    
    - 占位提示文本（Placeholder）：`请再次输入密码`
    - 交互：输入内容默认显示为密文。当输入内容与“密码设置输入框”不一致时，实时在其下方提示“两次输入的密码不一致”。

6. **注册按钮：**
    
    - 默认状态：可设置为置灰，当所有必填项（手机号、验证码、密码、确认密码）都按规则填写完毕后，按钮才变为可点击状态。
    - 点击后交互：触发提交注册信息的动作。

7. **服务协议勾选框：**
    
    - 文本描述：`我已阅读并同意《用户服务协议》和《隐私政策》`
    - 交互：默认可为未勾选状态。`《用户服务协议》`和`《隐私政策》`应为可点击的链接，点击后弹出相应文本内容。可将此项作为注册的必要条件，用户必须勾选后，“注册”按钮才能被点击。

8. **“已有账号？立即登录”链接：**
    
    - 交互：点击后，页面应跳转至“用户登录”页面。

#### 3.1.6 业务流程

在此处使用流程图或文字描述该功能的详细业务逻辑。

1. 用户进入注册页面。
2. 用户输入11位手机号，此时“获取验证码”按钮被激活。
3. 用户点击“获取验证码”按钮。
4. 前端向后端API发送“请求发送验证码”的请求，参数为手机号。
5. 后端API接收请求：
    - 首先校验该手机号是否已被注册，如果已注册，则返回错误信息“该手机号已被注册”。
    - 如果未被注册，则生成一个6位随机验证码，将其与手机号关联并存入缓存（如Redis），设置有效期（如5分钟）。
    - 调用第三方短信服务商接口，向该手机号发送验证码短信。
    - 向前端返回发送成功的响应。
6. 前端收到成功响应后，将“获取验证码”按钮置为60秒倒计时状态。
7. 用户收到短信，在页面上输入验证码、设置密码并确认密码，勾选同意服务协议。
8. 用户点击“注册”按钮。
9. 前端对所有输入项进行最终校验（如非空、密码一致性等）。
10. 校验通过后，前端将手机号、用户输入的验证码、密码等信息发送至后端“注册”API。
11. 后端API接收注册请求，并进行严格校验：
    - 校验验证码是否正确且未过期。
    - 再次校验手机号是否在此期间被注册。
    - 校验密码是否符合复杂度要求。
12. 所有校验通过后，后端执行以下操作：
    - 对用户密码进行加密处理（如加盐哈希）。
    - 在用户数据库中创建一条新的用户记录。
    - （可选）为用户自动生成登录凭证（Token），实现注册后自动登录。
    - 向前端返回注册成功的响应，并附带登录凭证。
13. 前端收到成功响应后，提示用户“注册成功”，保存登录凭证，并自动跳转到应用首页。如果后端返回任何错误，则在页面上显示相应的错误提示。

#### 3.1.7 异常/分支流程

A功能的异常流程与分支流程

- **验证码错误：** 提示“验证码错误”，不清空已输入内容。
- **手机号已注册：** 提示“该手机号已被注册”。
- **网络异常：** Toast提示“网络不给力，请稍后重试”。

A功能牵涉到的数据字典

| `mobile`   | String | 11位数字，唯一     | 用户手机号，作为登录凭证 |
| `password` | String | 8-16位，含字母和数字 | 加密存储         |

#### 3.1.9 验收标准

-  [ ] **正常流程：** 输入所有正确信息后，点击注册，提示成功并跳转到首页。
-  [ ] **手机号校验：** 输入非11位手机号时，实时提示格式错误。
-  [ ] **手机号重复校验：** 输入已注册的手机号，点击注册后提示“该手机号已被注册”。
-  [ ] **密码校验：** 两次输入的密码不一致时，实时提示错误。
-  [ ] **验证码校验：** 输入错误的验证码，点击注册后提示“验证码错误”。
-  [ ] **获取验证码按钮：** 点击后进入60秒倒计时，期间不可点击，倒计时结束后恢复。

以登录功能为例

#### 3.2.1 描述

对B功能的简单描述

作为[角色]，我想要[完成某个操作]，以便于[实现某个价值]。

#### 3.2.3 前置条件

- **用户状态：** 用户必须处于**未登录**状态。
- **数据依赖：** 用户的账号必须已存在于系统数据库中，且状态为“正常”（未被冻结或注销）。
- **用户位置：** 用户已打开应用的“登录”页面。

#### 3.2.4 后置条件

- **状态变更：** 系统成功验证用户信息后，该用户的会话状态更新为**已登录**。
- **界面跳转：** 页面自动跳转至**应用首页**。
- **数据加载：** 应用前端能够获取并展示该用户的基本信息（如昵称、头像）。

#### 3.2.5 界面及交互

B功能的界面，与界面各元素的说明及其交互

**界面元素说明：**

1. **手机号输入框：**
    - 占位提示文本（Placeholder）：`请输入手机号`
    - 交互：输入内容实时进行格式校验。
2. **密码输入框：**
    - 占位提示文本（Placeholder）：`请输入密码`
    - 默认显示为密文（•）。
    - 提供一个“眼睛”图标，点击可切换密码的明文/密文显示。
3. **登录按钮：**
    - 默认状态为激活。
    - 当手机号或密码为空时，可置为禁用状态。
4. **“忘记密码”链接：**
    - 点击后跳转至“找回密码”流程页面。
5. **“立即注册”链接：**
    - 点击后跳转至“用户注册”页面。

#### 3.2.6 业务流程

1. 用户在登录页面输入手机号和密码。
2. 用户点击“登录”按钮。
3. 前端对输入框内容进行非空校验。
4. 前端将手机号和密码加密后发送至后端API。
5. 后端API接收到请求，对手机号和密码进行校验。
    - **校验成功：** 生成用户身份令牌（Token），返回给前端，并附带成功状态码和用户信息。
    - **校验失败：** 返回失败状态码及对应的错误信息（如“手机号或密码错误”）。
6. 前端接收到后端响应：
    - **响应成功：** 在本地存储用户令牌，并执行页面跳转（至首页）。
    - **响应失败：** 在页面上显示对应的错误提示（Toast或在输入框下方显示）。

#### 3.2.7 异常/分支流程

- **手机号或密码错误：** 在页面顶部或按钮附近提示“手机号或密码错误”。（注意：为安全起见，不要明确指出是“手机号不存在”还是“密码错误”）。
- **账号被冻结：** 提示“您的账号已被冻结，请联系客服”。
- **输入格式错误：** 在对应的输入框下方实时提示，如“请输入11位手机号”。
- **请求超时/网络异常：** 弹出全局Toast提示“网络不给力，请稍后重试”。

#### 3.2.8 数据字典

| 字段名 | 数据类型 | 约束 | 备注 |
| :--- | :--- | :--- | :--- |
| `mobile` | String | 必填，11位数字 | 用于登录的手机号 |
| `password` | String | 必填，8-16位字符 | 用户登录密码，传输时需加密 |

#### 3.2.9 验收标准

**功能正确性**

-  [ ] 正常登录：输入已注册且状态正常的手机号和对应的正确密码，点击“登录”后，系统应成功登录并跳转到应用首页。
-  [ ] 密码错误：输入正确的手机号和错误的密码，点击“登录”，页面应提示“手机号或密码错误”，并停留在当前页。
-  [ ] 账号不存在：输入一个未注册的手机号，点击“登录”，页面应提示“手机号或密码错误”，并停留在当前页。
-  [ ] 账号被冻结：使用一个已被冻结的账号及其正确密码登录，页面应提示“您的账号已被冻结，请联系客服”。

**输入校验**

-  [ ] 必填项校验：手机号或密码任一项为空时，点击“登录”，应在对应的空输入框下方提示用户输入。
-  [ ] 手机号格式校验：在手机号输入框中输入非11位数字时，输入框下方应实时给出“请输入正确的手机号”的提示。

**交互体验**

-  [ ] 密码可见性切换：点击密码输入框旁的“眼睛”图标，密码应在明文和密文之间切换。
-  [ ] 链接跳转-忘记密码：点击“忘记密码”链接，应能正确跳转到“找回密码”页面。
-  [ ] 链接跳转-注册：点击“立即注册”链接，应能正确跳转到“用户注册”页面。

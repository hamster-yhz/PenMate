# Line Editing

Aim for precise, alive prose that still sounds like this author and viewpoint, not maximum smoothness.

## Editing Order

1. Protect meaning and constraints.
   - Identify POV, tense, factual content, emotional direction, voice markers, and any wording the user wants retained.
2. Clarify the paragraph.
   - Repair unclear reference, chronology, spatial logic, subject changes, and buried actions.
   - Put emphasis where the sentence and paragraph actually turn.
3. Strengthen diction.
   - Prefer specific nouns and active, accurate verbs.
   - Remove redundancy, filler, abstraction, accidental repetition, and modifiers that merely restate the verb.
   - Do not replace ordinary precise words with ornate synonyms.
4. Tune rhythm.
   - Vary sentence length and structure according to thought and pressure.
   - Preserve useful roughness, interruption, silence, and repetition when they carry voice or emotion.
5. Refine imagery and interiority.
   - Keep images coherent with viewpoint, setting, and emotional logic.
   - Replace generic emotional explanation with concrete perception, thought, or behavior only when it improves the passage.
6. Refine dialogue.
   - Preserve each speaker's objective, vocabulary, evasions, and status.
   - Cut greetings, confirmations, and explanations that add no tension or relationship information.
7. Run a conservation check: no altered fact, motivation, chronology, POV knowledge, or implied canon.

## Editing Intensity

- Light: correctness, clarity, and obvious repetition; retain syntax and texture.
- Medium: recast weak sentences and improve paragraph rhythm while preserving voice.
- Deep: substantially rewrite the language but preserve scene events, meaning, POV, and canon.

Infer the lowest sufficient intensity unless the user specifies one.

## Output Contract

Return the revised text directly. Explain changes only when requested or when an ambiguity forced a consequential choice. Never invent new plot facts to make a sentence easier to polish.
